# Roadmap

## 0.1 — Symbolic foundation
- [x] Modular C++ core and console
- [x] UTF-8 validation and basic Persian normalization
- [x] Language-independent concepts and aliases
- [x] Structured facts and provenance metadata
- [x] Dataset ingestion with diagnostics and line limits
- [x] Transitive inference and path explanations
- [x] Inverted retrieval index
- [x] Versioned binary persistence
- [x] CMake build and automated tests

## 0.2 — Language and data quality
- [ ] Full Unicode normalization and robust punctuation handling
- [ ] Canonical relation vocabulary and multilingual relation aliases
- [ ] Corpus validator, duplicate report, and provenance audit
- [ ] Contradiction detection and conflict policies
- [ ] Stable external concept IDs and safe concept merging

## 0.3 — Reasoning and retrieval
- [ ] Incremental worklist-based closure
- [ ] Backward chaining with depth and cycle limits
- [ ] Query intent templates for common question forms
- [ ] Synonym expansion and configurable ranking
- [ ] Explanation graph and confidence propagation

## 0.4 — Memory and interaction
- [ ] Session and episodic memory with user controls
- [ ] Interactive fact review and correction
- [ ] Import/export and snapshot migration tools

## 1.0 — Stable symbolic engine
- [ ] Public API compatibility policy
- [ ] Large-corpus benchmarks and memory profiling
- [ ] Fuzzing for text and binary parsers
- [ ] Reproducible release packaging

A roadmap item is complete only when code and tests exist.
