# Changelog

## 0.1.0 — Initial symbolic foundation

- C++26 console application and modular standard-library-only core.
- UTF-8 validation, basic Persian normalization, tokenization, and script detection.
- Language-independent concepts and aliases.
- Structured FACT / WORD / RULE / QA ingestion.
- Conservative English and Persian sentence-template extraction.
- Recursive, deterministic directory dataset training.
- Exact normalized Q/A retrieval with source attribution.
- Transitive reasoning and evidence-path explanations.
- Inverted retrieval, evidence coverage evaluation, and conservative answer composition.
- Bounded in-process session memory.
- Version 2 little-endian binary persistence with version 1 read compatibility.
- CMake presets, installable core target, CI workflow, and dependency-free tests.
